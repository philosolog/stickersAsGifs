# StickersAsGifs

Adds stickers to your Favorite GIFs.

Hover over a sticker in a message or the expression picker and click the GIF favorite star. Click again to remove it from Favorite GIFs. The star uses Discord's native GIF favorite control and also works with BetterGifLibrary when enabled. Lottie stickers are not supported.

You can also right-click a sticker and pick "Add to Favorite GIFs". This writes straight into Discord's native GIF favorites, so the sticker shows up in the GIF picker's Favorites tab and can be sent like any GIF — useful for sending stickers without Nitro or sticker-send permission.
