# StickersAsGifs

Adds stickers to your Favorite GIFs.

Right-click a sticker (on a message or in the expression picker) and pick "Add to Favorite GIFs". It writes straight into Discord's native GIF favorites, so the sticker shows up in the GIF picker's Favorites tab and can be sent like any GIF — useful for sending stickers without Nitro or sticker-send permission.
